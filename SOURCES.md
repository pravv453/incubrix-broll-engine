# Sources: models, APIs, libraries, data and media

Versions are the ones pinned in `uv.lock` (Python) and the image tags in `docker-compose.yml` / `Dockerfile`.
"Default path" means it is used by `docker compose up` without any API key.
Licence statements reflect the upstream licence files and terms pages as I understood them when building.
Items marked **verify** must be re-checked against the live terms before production use.

## External APIs and media sources

| Source | Used for | Licence / terms | How rights are recorded |
|---|---|---|---|
| Pixabay Videos API (`FOOTAGE_PROVIDERS=pixabay`) | stock footage | Pixabay Content License https://pixabay.com/service/license-summary/; API docs https://pixabay.com/api/docs/ (no hotlinking, 24 h cache, rate limits) (**verify**) | Per clip: asset id, page URL, creator, licence name and URL, restrictions, retrieval time, `evidence_status: provider_policy_v1` |
| Gemini image generation (`GENERATED_PROVIDER=gemini`) | AI-generated clips | Gemini API Terms | `is_ai_generated: true`, prompt and model stored in timeline |
| Mock stock library (`app/adapters/footage/mock.py`) | tests, keyless demo | Synthetic clips generated by our own ffmpeg filters (owned) | Same record shape as real providers |
| Mock image generator | tests, keyless demo | Synthetic (ffmpeg `mandelbrot`), owned | `is_ai_generated: true` |

No stock site is scraped. Pexels and Openverse were considered and **not** used. Pexels: new API keys were reported paused, and its terms restrict building similar services. Openverse/Flickr: aggregated licence metadata and frequent watermarks.

## Datasets

None used for training. Test inputs are synthetic (ffmpeg-generated tones, silence and clips) or scripts written for this project.
Real voiceovers used for evaluation must be the author's own recordings or recordings made with consent (listed in the test pack when added).
